# WALKRI machine-readable layer: moved to the one source

The machine-readable layer for this standard (JSON Schema, register, examples, and the
generator) is no longer kept in this repo. It lives as one source in the public
**[Polymathie-Studio/tools](https://github.com/Polymathie-Studio/tools)** repository:
source under `machine-readable/craft/walkri/`, the generated schema under `schema/craft/walkri/`,
indexed by the CRAFT family manifest.

This is a pointer, not a mirror, by design (one source).

- This standard's schema: https://raw.githubusercontent.com/Polymathie-Studio/tools/main/schema/craft/walkri/walkri.schema.json
- CRAFT family manifest: https://raw.githubusercontent.com/Polymathie-Studio/tools/main/schema/craft/craft-manifest.json
